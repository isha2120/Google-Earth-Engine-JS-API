## 📌 About the Project

Google Earth Engine is a cloud-based platform for processing and analysing geospatial data at a large scale. Its JavaScript API provides an interface for accessing satellite imagery, working with geospatial datasets, and creating visualisations.

This project provides a guided introduction to the Google Earth Engine JavaScript environment, helping new users understand its interface and the tools available for geospatial analysis.

## 📑 What's Covered

- **Introduction to Google Earth Engine:** Understanding the platform and its applications.
- **Code Editor Interface:** Exploring the different panels and tools.
- **JavaScript API:** Understanding how scripts are written and executed.
- **Map Visualisation:** Working with map layers, datasets and visualisation settings.
- **Script Management:** Exploring saved scripts, version history and sharing options.
- **Data and Geometry Tools:** Understanding data imports and drawing tools.

## 🚀 Getting Started

The guide is available directly through GitHub Pages. No local installation is required to read it.
